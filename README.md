# 🔥 FitGenie AI - Personalized Calories Predictor

## 📌 Overview

FitGenie AI is a Machine Learning web application that predicts the number of calories burned during exercise based on a user's personal and workout details.

The application is built using Python, Flask, Scikit-learn, HTML, CSS, JavaScript, and Tailwind CSS.

---

## ✨ Features

- Predict calories burned using Machine Learning
- Simple and responsive web interface
- Real-time prediction without reloading the page
- User-friendly input form
- Fast and lightweight Flask backend

---

## 🛠️ Tech Stack

- Python
- Flask
- Scikit-learn
- NumPy
- Joblib
- HTML
- Tailwind CSS
- JavaScript

---

## 📊 Machine Learning Model

**Algorithm Used:**
- Linear Regression

### Input Features

- Gender
- Age
- Height
- Weight
- Duration
- Heart Rate
- Body Temperature

### Output

- Estimated Calories Burned

## 🚀 How to Run

1. Clone the repository

```
git clone <repository-link>
```

2. Install dependencies

```
pip install -r requirements.txt
```

3. Run the Flask application

```
py app.py
```

4. Open your browser

```
http://127.0.0.1:5000
```
